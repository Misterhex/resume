## Guidelines for AI Assistants

1. **Content edits only** — This repo has no code to build, test, or lint. Changes are limited to Markdown editing.
2. **Preserve formatting** — Maintain the existing heading hierarchy (`##` for sections, `###` for roles, `####` for subsections), bold styling for titles/companies, and italic for date ranges.
3. **Do not fabricate information** — Never add, modify, or embellish resume content (job titles, dates, achievements, skills) without explicit instruction from the owner.
4. **Spelling and grammar** — Minor spelling/grammar fixes are acceptable when clearly erroneous, but flag them rather than silently changing meaning.
5. **No build or test steps** — There are no dependencies to install, no tests to run, and no build process.
